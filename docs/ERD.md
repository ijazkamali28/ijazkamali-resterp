# Entity relationship diagrams

_Generated by `npm run docs` from the migrated database (96 tables). Do not edit by hand._

Conventions: every table has a UUID `id` primary key (except pure link/derived tables), `company_id` (tenant), and where operational `branch_id`.
Audit columns (`created_by`, `updated_by`, approvers) and `company_id` → `org.companies` links exist on almost every table and are omitted from the diagrams for readability; see SCHEMA.md.
